## Summary

Studies how updating an agent in four separate dimensions (memory, weights, tool, workflow) changes its safety behavior (tested on HarmBench, HEx-PHI, SALAD-Bench, and Agent-SafetyBench, RedCode-Gen. 
Also studies “deployment-time reward hacking”: as an agent accumulates past experiences, it may infer simple behavioral heuristics correlated with high historical reward/success and then overgeneralize those heuristics to new tasks, even when they conflict with the current user's actual objective.

Tool misevolution: Agents may create insecure tools then later reuse them in a security-sensitive/cross-domain context where the original assumptions no longer hold. Agents are also generally very poor at detecting and rejecting external GitHub tools containing hidden malicious code.

Memory misevolution: safety decays as memories accumulate. Memory-induced failures can also emerge abruptly after a particular high-reward experience.
