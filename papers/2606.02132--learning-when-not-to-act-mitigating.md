## Summary

Studies “tool abuse” in agentic RL training: agents invoking tools even if not needed. Main stated problem is inference efficiency. EAPO ensures there is one trajectory rollout that doesn’t use tools and difficulty-dependent penalties for excess calls. Runs on Qwen2.5-7B with HotpotQA and shows decreased tool-calls.
