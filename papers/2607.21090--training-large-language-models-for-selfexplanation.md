## Summary

Studies explanatory faithfulness, which posits the model’s generated explanation should reflect the model’s decision-making process (in contrast to causal faithfulness: The CoT should causally affect the model’s final response; explanatory faithfulness need not be causal). Improves LLM’s explanatory faithfulness via a proposed RL setup based on prior work on measuring performance on counterfactuals. 
 
RL training setup is measured as follows: Given input $x$, fetch model’s output $y$ and explanation $e$. Now, intervene on $x$ via $\Delta$ and call it $x’$, and see how $y$ changes to $y’$. Reward the model if $\Delta$ is reflected in the difference between $y$ and $y’$; if yes, reward.

## Questions/Comments
- Explanation faithfulness exhibits poor generalization beyond the RL’d domain.
- Paper only studies instruct mode; thinking is turned off (?) for Qwen3-8B.
- Answer is multiple-choice. Signal $I$ is only 1 if the label flips, so. $p=0.51\rightarrow 0.99$ is treated as 0 whereas $p=0.49\rightarrow 0.50$ is treated as 1. 
- The “location of the explanation” is not where we expect it to be in practice. The model is rewarded for generating an explanation as the objective, instead of rewarded for generating faithful explanations for a task.
