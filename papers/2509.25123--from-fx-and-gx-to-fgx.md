Studies the question of whether fine-tuning with RL engraves new abilities into the model or does the model merely get better at using skills already possessed from initial pre-training. In contrast to previous studies that show RL merely does "reranking," proposes that RL teaches the skill of composition. Uses a synthetic string transformation task as test setting
