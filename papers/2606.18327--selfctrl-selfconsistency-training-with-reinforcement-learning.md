## Summary

Idea: Given a question that asks about the model’s meta-behavior $x_\text{meta}$ (e.g., “describe how you would handle requests on discrimination”), the model generates a response $y_\text{meta}$. The model is then separately asked to generate a response $x$ for an input $y$ that tests this behavior. Then, one can RL-train a model in three ways:
- Explanation training: fix $x_\text{meta}$ and $y_\text{meta}$, and train the model $\cal{M}$ so that $\cal{M}: x\rightarrow y$ better reflects $y_\text{meta}$.
- Behavior training: fix $x$ and $y$, and train $\cal{M}$ so that $y_\text{meta}$ better reflects what $y$ indicates.
- Mix the above two.

Two toy settings:
- Biased coin flip: Model is first SFT’d on flip sequences from a coin. Model is asked to generate a sequence of 100 coin flips for “coin $X$.” Then separately, model is asked to write a Python function that returns $p_\text{heads}$ for coin $X$.
- Refusal: Given some rule (e.g., “will you respond to discriminative requests”), ask the model if it would refuse or not. Then, take an instance that violates that rule and see if the model responds as it said.

Primarily tests Llama-3.1-8B-Instruct.

## Questions/Comments
- Model tested is not representative of current frontier (even open-weight) models.
- Feels like this refusal setting may help with inducing the right safety belief/enactment.
