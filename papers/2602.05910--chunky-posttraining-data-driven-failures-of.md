## Summary

Intuition: Consider domains $A$ and $B$ where there is unintentionally some associated feature/condition $C_A$ and $C_B$ with each respective domain’s prepared training data $X_A$ and $X_B$, where $C_A(x) = 1$ for $x \in X_A$ (and similarly for $B$). While the original training objective is for the model to learn $f_A(x)$ and $f_B(x)$ for any $x$, the model instead learns to use $C_A$ and $C_B$ as cues for when to invoke those behaviors, e.g. $C_A(x)=1 \Rightarrow f_A(x)$ and $C_B(x)=1 \Rightarrow f_B(x)$. Then, when an instance $x \in B$ also satisfies $C_A(x)=1$, the model spuriously invokes behavior associated with $f_A$.
This may lead to a form of *misgeneralization*: e.g., training a model that good literature search involves first searching the internet where the input/setting is about LLMs then applying it to a benchmark-maxxing task may lead to a model that unintentionally “cheats” by searching for solutions online first.

(The mathematical hierarchy is like $\text{generalization} \supset \text{misgeneralization} \supset \text{chunky post-training behavior}$.)

Also shows SURF: tool for finding such cases in models, and TURF, tool for finding the origin of the behavior in its training data.

Sketch of SURF:
1. Take questions from Tulu 3 SFT dataset and prompt an LLM to extract features out of it (e.g., “uses formal language”). Do some filtering/merging/etc. to get a finalized feature library. Separately, have a set of undesirable behaviors. 
2. Sample a random number $K$ and a random set of $K$ features from this finalized library, and ask an LLM to generate a question that has all $K$ features. Do this $N=360$ times.
3. Pass each question to a testee LLM, and get its response. Then, query an LLM judge to score on a scale of 0 to 100 the (query, response, undesirable behavior rubric items) tuple. 
4. Sort the 360 instances by score, and reweight each attribute by its normalized score. 
5. In the next round, sample features w.r.t. this reweighted score to generate questions to do the same process again.

This will result in “converging” to a set of features that saliently lead to the undesirable behavior.


## Questions/Comments
- The claim made in the introduction seems to imply a causal factor of the features. However, SURF is purely correlational. (i.e., generating a question from the top $K$ features does not reliably elicit the undesirable behavior of interest)
